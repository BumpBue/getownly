# โลโก้ธนาคาร

ไฟล์ในโฟลเดอร์นี้เป็น **static asset ของแอป** ไม่ได้อยู่บน MinIO
จึงไม่ต้องเซ็น URL ไม่มีวันหมดอายุ และติดไปกับ image ตอน `docker build` เลย

## ชื่อไฟล์

**ตั้งชื่อตามรหัสธนาคาร 3 หลักของ ธปท.** เช่น `004.gif` คือธนาคารกสิกรไทย
รายการรหัสทั้งหมดอยู่ที่ `packages/shared/src/banks.ts` ซึ่งเป็นแหล่งความจริงเพียงที่เดียว

> ⚠️ **เพิ่มหรือลบไฟล์แล้วต้องแก้ `logoFile` ใน `banks.ts` ด้วยเสมอ**
> โค้ดไม่ได้ประกอบชื่อไฟล์จากรหัส แต่อ่านชื่อเต็มพร้อมนามสกุลจากตารางนั้น
> เพราะนามสกุลของแต่ละไฟล์ไม่เหมือนกัน
> มีชุดทดสอบ (`banks.spec.ts`) ที่อ่านโฟลเดอร์นี้จริงแล้วจะ**ตก**ถ้าตารางอ้างไฟล์ที่ไม่มีอยู่

## รูปแบบและขนาด

| หัวข้อ | ที่แนะนำ |
|---|---|
| นามสกุล | `.svg` `.png` `.gif` `.jpg` `.webp` — เบราว์เซอร์โหลดได้หมด ไม่ต้องแก้โค้ด |
| ขนาด | **สี่เหลี่ยมจัตุรัส 500×500 px** เท่ากับไฟล์ชุดปัจจุบัน |
| พื้นหลัง | โปร่งใสดีที่สุด แต่พื้นขาวก็ใช้ได้ |

หน้าจอวางโลโก้ทุกอันใน**กรอบสี่เหลี่ยมพื้นขาวขนาดคงที่ พร้อม `object-contain`**
ไฟล์ที่พื้นหลังทึบ (เช่น `.jpg`) จึงดูเข้าชุดกับไฟล์ที่โปร่งใส และทุกโลโก้มีขนาดเท่ากันเสมอ
ไม่ว่าไฟล์ต้นทางจะมีสัดส่วนอย่างไร

## วิธีเพิ่มโลโก้ที่ยังขาด

1. วางไฟล์ในโฟลเดอร์นี้ ตั้งชื่อตามรหัส เช่น `071.svg`
2. แก้ `logoFile: null` ของธนาคารนั้นใน `packages/shared/src/banks.ts` เป็น `'071.svg'`
3. รัน `pnpm test` — `banks.spec.ts` จะยืนยันว่าตารางกับโฟลเดอร์ตรงกัน
